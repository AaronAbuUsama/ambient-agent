Ambient — the live loop

Every handoff between roles is a durable record. Agents never call each other; they read and write the middle, and deterministic services move the records.

Proven live, today

  • Bug report in the Tst group → speaker delegated → Worker filed real issue #8 → speaker reported "#8" back in the chat, observed by the second account
  • Memory keep-up: a live message digested by the running daemon, unprompted
  • Production ontology rebuilt: 134 identity-aware claims, 46 issues, 8 people
  • Crash recovery proven in anger: six live failures each fixed with retained evidence

Gated & measured

  • Golden memory coverage 20/22 (the bar); faithfulness mean 0.917
  • 146 unit tests; offline delegation rehearsal PASS incl. grant revocation
  • Three idempotency layers: claim-derived ids, retained receipts, issue markers
  • Destinations never model-chosen: repo and chat bound host-side

Known gaps

  • Images & videos invisible to memory and speaker (refs retained, content unseen)
  • Issue craft bar not met: no answer key, no worker evals yet
  • Worker results are prose, not structured done/declined
  • Skills front-loaded whole, not progressively disclosed
  • No Root agent; the operator authors definitions by hand
