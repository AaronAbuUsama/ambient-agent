# Reference copies of what the Root authored

The live copies of these live in the Ambient home, which is operator-owned
and deliberately outside this repository:

| Reference here             | Live at                                                   |
| -------------------------- | --------------------------------------------------------- |
| `bug-intake.md`            | `~/.ambient/chats/bug-reports/skills/bug-intake/SKILL.md` |
| `github-issues.agent.yaml` | `~/.ambient/agents/github-issues/agent.yaml`              |

They are copied in so the craft is reviewable in a pull request and
recoverable if a home is lost. The home copy is the one that runs — editing
the file here changes nothing.

These are where the judgement lives. The machinery decides what Ambient
_can_ do; these decide whether what it does is any good. The first live
media proof filed a thin issue from a screenshot captioned "this is wrong
again", and the cause was here, not in the code: the chat had been told to
delegate on sight and the definition had no permission to decline.
